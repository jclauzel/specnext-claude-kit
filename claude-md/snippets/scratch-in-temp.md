# Snippet: the scratchpad can be wiped

Claude Code sessions often work in a scratch folder under the system's temporary directory, which the operating
system or a cleanup tool can empty. Paste the block into your user or project `CLAUDE.md`.

```markdown
## The scratchpad can be wiped
- The session scratchpad lives in the system's temporary folder and can be wiped at any time. Nothing that is needed
  again lives only there: tools go in the repo (under `extra/`), notes and decisions in the repo's docs or a notes
  repo, and evidence worth keeping is copied somewhere durable before the session ends.
```
